# Видеоинтервью

Простой сайт для видеозвонка один на один на WebRTC. Сборка и установка библиотек не нужны.

## Как проверить

1. Откройте `index.html` через локальный сервер или опубликуйте сайт на GitHub Pages.
2. Откройте страницу в двух окнах браузера.
3. Нажмите «Начать звонок» в обоих окнах и разрешите доступ к камере и микрофону.

Для доступа к камере браузеру нужен безопасный контекст: `https://` или `localhost`.

## Как опубликовать на GitHub Pages

1. Создайте GitHub-репозиторий и загрузите в него файлы `index.html`, `style.css`, `app.js` и `README.md`.
2. В репозитории откройте **Settings → Pages**.
3. В разделе **Build and deployment** выберите **Deploy from a branch**, затем ветку `main` и папку `/ (root)`.
4. Сохраните настройки и откройте ссылку, которую покажет GitHub Pages.

## Как работает звонок

- WebSocket по адресу `wss://inai-col3.fishrungames.com/signaling/` пересылает сообщения между участниками.
- WebRTC передаёт аудио и видео напрямую между браузерами.
- Случайные ID участников помогают выбрать одного браузера, который создаёт offer.
- STUN-сервер помогает браузерам найти сетевой маршрут друг к другу.
